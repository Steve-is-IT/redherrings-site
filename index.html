Ten kinds of real evidence

Disk images, registry hives, Windows event logs, Prefetch, LNK and jump lists, Chrome and Firefox history, email, network captures, cloud audit logs, memory and mobile databases, all in genuine on-disk formats.

Every answer independently verified

After generation, each artifact is re-opened with a separate parser and every answer on the key is confirmed present in the evidence. If it is on the key, it is in the file. We call it the Fresh Catch check.

One case, a different lab per student

Names, timestamps, hashes, IPs and answers all change per student from a single seed. Shared answers stand out instantly, and the same seed reproduces the exact labs on any machine.

Auto-grading with sensible tolerances

Hashes compare case-insensitively, timestamps within seconds, free text by fuzzy match with a review flag. Every score shows why it was awarded, so you can override with one click.

Grade the whole class at once

Fill one grading sheet, import it, and get a full gradebook plus class analytics: mean, median, distribution, per-question correct rate, and the questions that tripped everyone up.

Catch collusion, not just cheating

Frequently asked questions

Does it phone home or upload student data?

No. Generation and grading run entirely on your machine with no network call. The only time the software contacts a server is to activate, refresh or deactivate a license, when it sends just the license key, a derived machine id, the hostname and the app version. Air-gapped labs activate offline.

How do I know the answer key is correct?

After generating each lab, Red Herrings re-opens every artifact with an independent parser (The Sleuth Kit, python-registry, python-evtx, LnkParse3, dpkt and others) and confirms each answer is present in the evidence. The result is the green Fresh Catch checklist. Answers are computed from the generated evidence, never hard-coded.

Which forensic tools do the artifacts work with?

The evidence is written in real on-disk formats, so it opens in Autopsy, FTK Imager, Registry Explorer, EvtxECmd, PECmd, JLECmd, Wireshark, Volatility-style workflows, and standard SQLite and email tools.

Can I get grades into Canvas, Blackboard, Moodle or D2L?

Yes. Grade the whole class in Red Herrings, then export a grade file in Canvas, Blackboard, Moodle or D2L Brightspace format, with an optional per-student feedback note listing what each learner missed. You can also export a case as a Common Cartridge (.imscc) content module that imports into any conformant LMS.

Is there anything to help beginners learn?

Yes. Guided mode on the Solution screen steps a learner from a nudge about where to look, to how to work the question with the right tool, to the answer, one question at a time, instead of showing everything at once. An optional guided worksheet prints a short hint under each question and a tool quick-start appendix, so students can start away from the app. Forty-two cases run from first-look triage to multi-hour capstones, with a First Look on-ramp for every core skill.

Can I write my own scenarios?

Yes. The visual editor validates live and previews a resolved answer key, so you see exactly what a student will get. Export a pack to share or sell it.

Can I remove the Red Herrings branding?

Yes, with a white-label license. One setting rebrands every screen and document with your institution or company identity.
