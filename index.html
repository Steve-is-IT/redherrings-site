Evidence you can open. Answers you can trust. Grading that does itself.

Not multiple-choice quizzes dressed up as forensics. Red Herrings generates the real thing for both disciplines: authentic artifacts in the formats of the job, a verification pass that proves every answer is actually in the evidence, and a different investigation for every learner.

01

Real evidence, in the formats they'll meet on the job

  • Digital forensics: disk images, registry hives, Windows event logs, memory captures, PCAPs, Prefetch, LNK and jump lists, browser history, email, cloud audit logs and mobile databases, all in genuine on-disk formats.
  • Incident response: EDR detection feeds, SIEM alert exports, proxy and firewall logs and host telemetry, mapped to MITRE ATT&CK and tagged with the NIST 800-61 phases, so students respond the way a responder does.
  • Opens in the tools of the trade: Autopsy, FTK Imager, Registry Explorer, EvtxECmd, Wireshark, Volatility and standard SQLite and email tools.
02

A different investigation for every student

  • Names, timestamps, hashes, IPs and answers all change per student from a single seed, so no two people get the same lab. A copied answer is simply the wrong answer.
  • Catch collusion, not just cheating: a per-question report shows which student pairs look most alike.
03

Every answer is proven to be in the evidence

  • After generation, each artifact is re-opened with an independent parser and every answer on the key is confirmed present in the file. We call it the Fresh Catch check.
  • Answers are computed from the generated evidence, never hard-coded, so the key cannot drift from the files a student receives.
04

You never build or hand-grade a lab again

  • Auto-grading with sensible tolerances: hashes compare case-insensitively, timestamps within seconds, free text by fuzzy match with a review flag. Every score shows why, and you can override with one click.
  • Grade the whole class at once, with class analytics and per-question correct rates. Export grades to Canvas, Blackboard, Moodle or D2L, or post them automatically over LTI 1.3.
  • Students can solve in the browser: a private link per student, practice mode or a timed exam, graded on your machine with the answer key never reaching the page.
05

Built for how forensics is actually taught

  • A learning on-ramp: guided mode walks a stuck learner from where to look, to how to work it with the right tool, to the answer, one question at a time. Or run any case as a capture-the-flag.
  • Investigation report and chain of custody: a court-ready template with the evidence manifest and hashes pre-filled. The discipline employers hire for, that most courses skip.
  • Certification-prep and ATT&CK tracks: filter forensics cases by cert path (GCFE, GCFA, GNFA, GCFR, EnCE, Cellebrite, Magnet) and incident-response cases by MITRE ATT&CK tactic, or follow a learning pathway from first look to capstone.

Frequently asked questions

Does it phone home or upload student data?

No. Generation and grading run entirely on your machine with no network call. The only time the software contacts a server is to activate, refresh or deactivate a license, when it sends just the license key, a derived machine id, the hostname and the app version. Air-gapped labs activate offline.

How do I know the answer key is correct?

After generating each lab, Red Herrings re-opens every artifact with an independent parser (The Sleuth Kit, python-registry, python-evtx, LnkParse3, dpkt and others) and confirms each answer is present in the evidence. The result is the green Fresh Catch checklist. Answers are computed from the generated evidence, never hard-coded.

Which forensic tools do the artifacts work with?

The evidence is written in real on-disk formats, so it opens in Autopsy, FTK Imager, Registry Explorer, EvtxECmd, PECmd, JLECmd, Wireshark, Volatility-style workflows, and standard SQLite and email tools.

Can I get grades into Canvas, Blackboard, Moodle or D2L?

Yes. Grade the whole class in Red Herrings, then export a grade file in Canvas, Blackboard, Moodle or D2L Brightspace format, with an optional per-student feedback note listing what each learner missed. You can also export a case as a Common Cartridge (.imscc) content module that imports into any conformant LMS.

Is there anything to help beginners learn?

Yes. Guided mode on the Solution screen steps a learner from a nudge about where to look, to how to work the question with the right tool, to the answer, one question at a time, instead of showing everything at once. An optional guided worksheet prints a short hint under each question and a tool quick-start appendix, so students can start away from the app. Dozens of cases run from first-look triage to multi-hour capstones, with a First Look on-ramp for every core skill.

Does it cover incident response, or only forensics?

Both. 48 cases are digital forensics (disk, registry, event logs, memory, network, mobile, cloud) and 23 are incident response, worked from EDR detection feeds and SIEM exports, mapped to MITRE ATT&CK and tagged with the NIST 800-61 phases. Every plan includes both.

Do students need to install anything?

No. Hand each student a zip to work in their own tools, or a private link to the student portal, where they read the evidence and answer in the browser. Grading runs on your machine either way.

Can I write my own scenarios?

Yes. The visual editor validates live and previews a resolved answer key, so you see exactly what a student will get. Export a pack to share or sell it.

Can I remove the Red Herrings branding?

Yes, with a white-label license. One setting rebrands every screen and document with your institution or company identity.
