Evidence you can open. Answers you can trust. Grading that does itself.

Not multiple-choice quizzes dressed up as forensics. Red Herrings makes the real thing: authentic artifacts in the formats of the job, a verification pass that proves every answer is actually there, and a different investigation for every learner.

01

Real evidence, in the formats they'll meet on the job

  • Disk images, Windows event logs, registry hives, memory captures for Volatility-style analysis (processes, injected code, unlinked modules, connections), network captures (PCAP), Prefetch, LNK and jump lists, browser history, email, cloud audit logs and mobile databases — all in genuine on-disk formats.
  • Opens in the tools of the trade — Autopsy, FTK Imager, Registry Explorer, EvtxECmd, PECmd, JLECmd, Wireshark, Volatility-style workflows, and standard SQLite and email tools.
02

A different investigation for every student

  • Names, timestamps, hashes, IPs and answers all change per student from a single seed, so no two people get the same lab, and the same seed reproduces the exact labs on any machine. A copied answer is simply the wrong answer.
  • Catch collusion, not just cheating — a per-question report shows how many distinct answers went out and which student pairs look most alike. Copied work has nowhere to hide.
03

Every answer is proven to be in the evidence

  • After generation, each artifact is re-opened with a separate parser and every answer on the key is confirmed present. If it is on the key, it is in the file — we call it the Fresh Catch check.
  • Answers are computed from the generated evidence, never hard-coded, so the key can never drift from the files a student actually receives.
04

You never build or hand-grade a lab again

  • Auto-grading with sensible tolerances — hashes compare case-insensitively, timestamps within seconds, free text by fuzzy match with a review flag. Every score shows why it was awarded, so you can override with one click.
  • Grade the whole class at once from one sheet, with a gradebook and analytics: mean, median and per-question correct rate. Export grades to Canvas, Blackboard, Moodle or D2L, or package a case as a Common Cartridge module.
  • Students can solve in the browser too — a private link, graded on your machine, with the answer key never reaching the page. Optional, and covered on its own page.
05

Built for how forensics is actually taught

  • A learning on-ramp — guided mode walks a stuck learner from where to look, to how to work it with the right tool, to the answer, one question at a time. Reveal a full walkthrough, or run any case as a capture-the-flag with per-team flags and a CTFd import.
  • Investigation report & chain of custody — a court-ready template with the evidence manifest and SHA-256 hashes pre-filled, a transfer log and a finding-per-question write-up. The discipline employers hire for, that most courses skip.
  • Certification-prep tracks — filter the library by cert path (Foundations, Windows, Mobile, Network, Cloud, Linux, macOS, Advanced Forensics & IR), aligned to GCFE, GCFA, GNFA, GCFR, the SANS macOS and Linux tracks and vendor exams (ACE, EnCE, Cellebrite, Magnet).
  • Your brand on every document, or none — one setting puts your institution's name, logo and colors on every screen and generated document, or strips the branding entirely.

Frequently asked questions

Does it phone home or upload student data?

No. Generation and grading run entirely on your machine with no network call. The only time the software contacts a server is to activate, refresh or deactivate a license, when it sends just the license key, a derived machine id, the hostname and the app version. Air-gapped labs activate offline.

How do I know the answer key is correct?

After generating each lab, Red Herrings re-opens every artifact with an independent parser (The Sleuth Kit, python-registry, python-evtx, LnkParse3, dpkt and others) and confirms each answer is present in the evidence. The result is the green Fresh Catch checklist. Answers are computed from the generated evidence, never hard-coded.

Which forensic tools do the artifacts work with?

The evidence is written in real on-disk formats, so it opens in Autopsy, FTK Imager, Registry Explorer, EvtxECmd, PECmd, JLECmd, Wireshark, Volatility-style workflows, and standard SQLite and email tools.

Can I get grades into Canvas, Blackboard, Moodle or D2L?

Yes. Grade the whole class in Red Herrings, then export a grade file in Canvas, Blackboard, Moodle or D2L Brightspace format, with an optional per-student feedback note listing what each learner missed. You can also export a case as a Common Cartridge (.imscc) content module that imports into any conformant LMS.

Is there anything to help beginners learn?

Yes. Guided mode on the Solution screen steps a learner from a nudge about where to look, to how to work the question with the right tool, to the answer, one question at a time, instead of showing everything at once. An optional guided worksheet prints a short hint under each question and a tool quick-start appendix, so students can start away from the app. Dozens of cases run from first-look triage to multi-hour capstones, with a First Look on-ramp for every core skill.

Can I write my own scenarios?

Yes. The visual editor validates live and previews a resolved answer key, so you see exactly what a student will get. Export a pack to share or sell it.

Can I remove the Red Herrings branding?

Yes, with a white-label license. One setting rebrands every screen and document with your institution or company identity.
