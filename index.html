Real evidence, and an answer key checked against it

These aren't multiple-choice quizzes dressed up as forensics. The artifacts come in the real formats of the job, and the answer key is checked against them before anyone sees it.

01

Real evidence, in the formats they'll meet on the job

  • Digital forensics: disk images, registry hives, Windows event logs, Windows and Linux memory images, PCAPs, Prefetch, LNK and jump lists, browser history, email, cloud audit logs and mobile databases, all in genuine on-disk formats.
  • Incident response: EDR detection feeds, SIEM alert exports, packet captures and host event logs, mapped to MITRE ATT&CK and tagged with the NIST 800-61 phases, so students respond the way a responder does.
  • Opens in the tools of the trade: Autopsy, FTK Imager, Registry Explorer, EvtxECmd, Wireshark, Volatility 3 and standard SQLite and email tools.
02

A different investigation for everyone

  • Names, timestamps, hashes and IPs change from one seed, and so do about four in five answers across the library.
  • See what the class shares: a per-question report counts the different answers handed out and lists the student pairs whose keys match most.
03

The key is checked against the files

  • Every answer is computed from the generated evidence, never hard-coded, then confirmed present in each file by an independent parser before release. This is the verification check.
04

Grading that shows its work

  • Auto-grading with sensible tolerances: hashes ignore case, timestamps allow a few seconds, free text is fuzzy-matched and flagged for review. Every score shows why.
  • Grade the whole class at once, see per-question correct rates, and export to Canvas, Blackboard, Moodle or D2L, or post over LTI 1.3.
  • Students can solve in the browser: a private link per student, practice or timed exam, with the answer key never reaching the page.
05

Built for how forensics is actually taught

  • A learning on-ramp: guided mode walks a stuck learner from where to look, to how to work it, to the answer, one question at a time. Or run any case as a capture-the-flag.
  • Investigation report and chain of custody: a court-ready template with the evidence manifest and hashes already filled in, which is the part employers hire for and most courses skip.
  • Certification-prep and ATT&CK tracks: filter forensics cases by cert path (GCFE, GCFA, GNFA, GCFR, EnCE, Cellebrite, Magnet) and incident-response cases by MITRE ATT&CK tactic, or follow a learning pathway from first look to capstone.

Frequently asked questions

Does it phone home or upload student data?

No. Generation and grading run entirely on your machine with no network call. The software contacts a server only to activate, refresh or deactivate a license, when it sends only the license key, a derived machine id, the hostname and the app version, and to check GitHub for a new version if you turn that on. Air-gapped labs activate offline.

How do I know the answer key is correct?

After generating each lab, Red Herrings re-opens every artifact with an independent parser (The Sleuth Kit, python-registry, python-evtx, LnkParse3, dpkt and others) and confirms each answer is present in the evidence. The result is the green Verified checklist. Answers are computed from the generated evidence, never hard-coded.

Which forensic tools do the artifacts work with?

The evidence is written in real on-disk formats, so it opens in Autopsy, FTK Imager, Registry Explorer, EvtxECmd, PECmd, JLECmd, Wireshark, Volatility 3, and standard SQLite and email tools.

Can I get grades into Canvas, Blackboard, Moodle or D2L?

Yes. Grade the whole class in Red Herrings, then export a grade file in Canvas, Blackboard, Moodle or D2L Brightspace format, with an optional per-student feedback note listing what each learner missed. You can also export a case as a Common Cartridge (.imscc) content module that imports into any conformant LMS.

Is there anything to help beginners learn?

Yes. Guided mode on the Solution screen steps a learner from a nudge about where to look, to how to work the question with the right tool, to the answer, one question at a time, instead of showing everything at once. An optional guided worksheet prints a short hint under each question and a tool quick-start appendix, so students can start away from the app.

Does it cover incident response, or only forensics?

Both. Digital forensics cases cover disk, registry, event logs, memory, network, mobile and cloud evidence. Incident response cases are worked from EDR detection feeds and SIEM exports, mapped to MITRE ATT&CK and tagged with the NIST 800-61 phases. Every plan includes both.

Do students need to install anything?

No. Hand each student a zip to work in their own tools, or a private link to the student portal, where they read the evidence and answer in the browser. Grading runs on your machine either way.

Can I write my own scenarios?

Yes. The visual editor validates live and previews a resolved answer key, so you see exactly what a student will get. Export a pack to share or sell it.

Can I remove the Red Herrings branding?

Yes, with a white-label license. One setting rebrands every screen and document with your institution or company identity.
