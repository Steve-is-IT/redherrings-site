Help & getting started

Everything you need to go from download to a graded class. Most people are generating their first lab within five minutes.

1. Install & activate

  1. Download the build for your OS from the download section — Windows or Linux.
  2. Unzip it and run RedHerrings (Windows: RedHerrings.exe). It starts a local server and opens in your default browser — no installer, no admin rights needed.
  3. It runs immediately as a 14-day trial: three sample cases (one easy, one medium, one hard), up to 5 students per lab, and watermarked documents — no key required.
  4. When you buy, your license key arrives by email within a minute. In the app, open Settings → Licensing, paste the key, and click Activate.

To work the cases you also need forensics tools (Autopsy, Volatility, Wireshark and friends). See Tools & setup for one-run install scripts and the toolkit each certification track uses.

Verify your download: each release publishes SHA256SUMS.txt. On Linux run sha256sum -c SHA256SUMS.txt; on Windows run Get-FileHash RedHerrings-windows.zip -Algorithm SHA256 and compare.

2. Generate a lab for the whole class

  1. Open Case Library and pick a case. Filter by difficulty or by certification track; open a card to read the briefing and questions first.
  2. Go to Generate Labs and set:
    • Students — a head count (creates student-001, student-002, …) or import a roster CSV (any common column names work).
    • Difficulty — higher difficulty injects more noise (decoy files, extra accounts, more background traffic).
    • Seed — any text. The same seed and roster reproduce the exact same labs, so you can regenerate a lost package or rebuild on another machine. Use a new seed each term.
    • Formats — PDF, DOCX, or both; optionally the guided worksheet.
  3. Click Generate. Each lab is built and then verified — every artifact is re-opened with an independent parser to confirm the answer key is really in the evidence (the green "Fresh Catch" check).

3. Hand out to students

Each student gets a LAB-<case>-<student>.zip with their unique evidence, a worksheet, and a hash manifest. Hand each student only their own zip. The instructor package holds the answer keys, rubrics, and a grading sheet — keep that one.

4. Grade & export to your LMS

  1. Collect answers, fill the grading sheet, and import it under Grading to auto-grade the whole class at once. Tolerances are sensible: hashes case-insensitive, timestamps within seconds, text fuzzy-matched with a review flag. Every score shows why it was awarded.
  2. Review the class analytics — mean, median, distribution, and the per-question correct rate that shows what tripped everyone up.
  3. Export grades in Canvas, Blackboard, Moodle or D2L Brightspace format (or generic CSV), with an optional per-student feedback note listing missed questions. You can also export a case as a Common Cartridge (.imscc) module.
  4. Run the anti-collusion report to see, per question, how many distinct answers were handed out and which student pairs look most alike.

Guided mode (for stuck or self-study learners)

On the Solution screen, guided mode steps a learner one question at a time: from a nudge about where to look, to how to work it with the right tool, to the answer — instead of revealing everything at once. Turn it into a printable guided worksheet at generation time to add a hint under each question plus a tool quick-start appendix. You control whether learners may reveal solutions.

Disciplines and certification-prep tracks

The Case Library filters first by discipline — Digital Forensics or Incident Response — then by difficulty and by the path a case exercises. Digital Forensics cases group into Cert path tracks; Incident Response cases group by MITRE ATT&CK tactic. Tracks are aligned to the published topics of popular DFIR certifications (topic alignment, not endorsement):

Digital Forensics tracks

  • Foundations — entry-level fundamentals (AccessData ACE, CompTIA Security+).
  • Windows Forensics — GCFE, plus the disk domains of EnCE / ACE.
  • Mobile Forensics — Cellebrite CCO/CCPA, Magnet, GASF.
  • Network Forensics — GNFA.
  • Cloud & SaaS — identity and cloud audit logs (GCFR).
  • Linux Forensics — SANS FOR577.
  • macOS Forensics — SANS FOR518.
  • Advanced Forensics & IR — GCFA.

Incident Response tracks work the responder's own EDR and SIEM feeds, mapped to MITRE ATT&CK tactics and the NIST 800-61 phases — with learning pathways for Incident Handling (GCIH), SOC Analyst & Triage (CompTIA CySA+), Cloud & Enterprise IR (GCFR) and Advanced Forensics & IR (GCFA).

Pick a discipline and track to see the cases that prepare you for that exam's topics. Browse the full catalog → or follow a learning pathway.

CTF mode

Run any case as a capture-the-flag: per-team flags and a CTFd import file, so you can drop a Red Herrings case straight into a competition or a class challenge.

Offline & air-gapped use

Generation and grading run entirely on your machine with no network call. The only time the app contacts a server is to activate, refresh or deactivate a license — and air-gapped machines can activate offline with a request/response file. No student data ever leaves your computer.

Troubleshooting

  • Windows SmartScreen warning: the app is unsigned for now. Choose More info → Run anyway, or verify the download against SHA256SUMS.txt first.
  • "All seats in use": each license activates on a set number of machines. Open Settings → Licensing on a machine you no longer use and click Deactivate to free a seat.
  • Lost your key: email sales@redherrings.app and we'll resend it.
  • Browser didn't open: the terminal prints a local address (for example http://127.0.0.1:PORT/) — open it manually.
