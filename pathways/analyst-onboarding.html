Role path · Digital Forensics

SOC analyst onboarding labs, one evidence family at a time

A new analyst is expected to recognise every evidence family a ticket can throw at them: what ran on a host, where a file came from, what the Security log says about accounts and services, what is set to run at startup, which USB device was plugged in, what a packet capture shows, what is in memory, and what a phone holds, then to put several of those into a single timeline.

This pathway is the first-look tour in the order a new hire should meet it. Nine 25-minute First Look cases each isolate one artifact family, and the tenth is a full, if gentle, misconduct case that asks the analyst to use several of them together. It is the week-one curriculum we would hand a new SOC or DFIR analyst.

The pathway, in order

10 cases, about ~4 h 40 min of lab time. Each step opens the case in the library, where you can read the brief, the evidence list and the question set. Every student gets a different variant of the same case, graded against a key that was verified in the evidence.

  1. 01

    First Look: What Ran on This Machine

    Start with execution artifacts: what ran on a machine.

    EASY~25 min10 questions
  2. 02

    First Look: Suspicious Download

    EASY~25 min12 questions
  3. 03

    First Look: Accounts and Services in the Logs

    Read the security event log for accounts and services.

    EASY~25 min10 questions
  4. 04

    Find what a program set to run at startup.

    EASY~25 min10 questions

    Open a packet capture and follow a conversation.

    EASY~25 min11 questions

    Read process and connection lists from a memory image.

  8. 08

    First Look: Recovered Phone

    Recover messages from a mobile extraction.

    EASY~25 min10 questions

Who it is for

  • Security teams onboarding new analysts who want a graded, repeatable first week instead of shadowing.
  • Instructors opening a DFIR course who need a survey of evidence types before the deeper units.
  • Career changers and students who want to find out which part of DFIR they like before specialising.

What you get with every case

  • A different variant per student. Same case, same rubric, different names, hashes, timestamps and answers, so students can talk about method without sharing answers.
  • Evidence in the real on-disk format. Registry hives, EVTX, PCAP, SQLite, JSON audit logs and memory images open in the tools the exam expects.
  • A verified answer key. Every answer is re-derived from the planted evidence before the lab ships, so grading disputes end at the artifact.
  • One-click grading and LMS export. Canvas, Blackboard, Moodle, D2L and LTI 1.3 grade passback, or a CSV. See the student portal.
  • Runs on the instructor's machine. Windows installer plus macOS and Linux, fully offline after activation. Nothing to host and no student data leaves the room. Course packs on courses.
