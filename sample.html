Download a free sample forensic lab

Real evidence, not a screenshot. This is one complete Red Herrings case — a Windows insider-threat USB exfiltration — with the raw artifacts, a student worksheet, and a verified answer key. Open it in the tools you already teach with, work the questions, and check your findings against the key. No account, no install, no email required.

Download the sample lab (ZIP, 640 KB) Or solve one in your browser

The disk image expands to 64 MB. Everything is synthetic: no real personal data, safe to open on any machine.

What's in the ZIP

A faithful slice of a compromised Windows workstation, written in real on-disk formats — the same evidence a responder would pull, laid out the way it sits on disk.

A raw disk image

evidence.dd — a 64 MB raw image you can mount or load straight into Autopsy or FTK Imager and carve.

Registry hives

NTUSER.DAT, SYSTEM and SOFTWARE — USB device history, user activity and system configuration, for Registry Explorer or RegRipper.

Windows event logs

Security.evtx and System.evtx in native binary EVTX, for EvtxECmd, Event Viewer or your SIEM pipeline.

Execution and file-access artifacts

Prefetch (7ZFM.EXE, CHROME.EXE and more), LNK files and a jump list showing the documents and archives that were opened.

A filesystem timeline

An $MFT timeline CSV plus a full HASH-MANIFEST so you can verify every artifact is intact.

Worksheet and answer key

A student worksheet (PDF and DOCX) with the case briefing and questions, and the verified answer key so you can grade yourself.

Open it in the tools you already use

The evidence is written in authentic formats, so there is nothing proprietary to learn. It opens in the standard DFIR toolset:

AutopsyFTK ImagerThe Sleuth KitRegistry ExplorerRegRipperEvtxECmdEvent ViewerPECmdJLECmd / LECmdWiresharkVolatilityDB Browser for SQLite

New to a tool? The Tools & setup page lists where to get each one, and the blog walks through the techniques this case uses.

The catch: every student gets a different one

This download is student 001. In a class, Red Herrings generates a different version of this same case for every student — their own device serial, user, file names, timestamps and answers — so a copied answer is the wrong answer. Every generated lab is independently re-solved and verified before release, so the answer key is provably correct against that student's evidence. That is the whole product: author a case once, hand out a unique, self-grading lab to each learner, and grade the class at once.
