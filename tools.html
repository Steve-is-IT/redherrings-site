Set up your forensics toolkit

Red Herrings generates real evidence in real formats, so you work it with the same free tools used on the job. Run one script to install them, or pick per case from the map below.

Red Herrings does not install these tools for you, and it never phones home. Everything below is free and open, installed straight from the vendor. The commercial and hand-download tools are noted as such.

One-run install

The scripts install the free toolkit from each vendor (nothing is bundled or redistributed), and print links for the two tools whose licenses require a manual download.

Windows

Installs via winget. In an elevated PowerShell:

powershell -ExecutionPolicy Bypass -File setup-windows.ps1
Download setup-windows.ps1

Linux (Debian/Ubuntu)

Installs via apt and pip:

chmod +x setup-linux.sh && ./setup-linux.sh
Download setup-linux.sh

What each track needs

Every case lists its suggested tools, and the guided worksheet prints a quick-start for each. Here is the toolkit by certification track, so you install only what a track uses.

Foundations & Windows Forensics

  • Autopsy or The Sleuth Kit — disk images, deleted-file recovery, carving. Free.
  • Eric Zimmerman's tools (PECmd, LECmd, JLECmd, RECmd, EvtxECmd, Timeline Explorer) — Prefetch, LNK, jump lists, registry, event logs, timelines. Free.
  • Registry Explorer — registry hives (USB history, UserAssist, RecentDocs). Free.
  • Event Viewer (built into Windows) or Chainsaw — EVTX logon, account and log-clearing events. Free.
  • DB Browser for SQLite — Chrome/Firefox history databases. Free.
  • FTK Imager — mount and preview images. Free, hand-download (Exterro).

Mobile Forensics

  • ALEAPP — Android logs, events and app data. Free.
  • DB Browser for SQLite — SMS, WhatsApp msgstore, contacts and location databases. Free.

Network Forensics

  • Wireshark / tshark — packet captures: DNS, HTTP payloads, beacons, cleartext credentials. Free.

Advanced Forensics & IR

  • Volatility 3 — memory: processes, network connections, injected code. Free.
  • jq — cloud audit logs (CloudTrail, M365, Azure sign-ins) as JSON. Free.
  • Thunderbird — email mailboxes (mbox) and loose .eml. Free.
  • Plus the Windows, mobile and network tools above, since intrusion cases span several evidence types.

Prefer a ready-made distro?

SANS SIFT Workstation is a free, maintained Linux VM that already bundles most of the above (Sleuth Kit, Volatility, Wireshark, and more). If you would rather not install tools yourself, or you want a clean disposable analysis environment, download SIFT and point it at your lab's evidence.

Get SIFT Workstation

SIFT covers the disk, memory, network and Linux tracks well — the Linux cases are plain-text logs you read with grep and any editor. For the Windows-artifact cases, add Eric Zimmerman's tools (they run under dotnet on Linux, or natively on a Windows VM). For the macOS cases, mac_apt parses the unified log, quarantine, Safari and plists, and DB Browser opens the SQLite stores directly.

Tools you download by hand

Two tools cannot be scripted because their licenses require you to accept terms or fetch a release yourself:

  • FTK Imager — exterro.com (free, form required).
  • Chainsaw — GitHub releases (free, EVTX threat hunting).
