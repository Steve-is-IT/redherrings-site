Evaluating Red Herrings for a forensics or incident response program

A one-page summary for a chair, curriculum committee or purchasing office. It covers what the software does, how to check it in a free trial, what a purchase involves, and the answers security and procurement reviewers usually need.

What it is

A desktop application for Windows, macOS and Linux that generates digital forensics and incident response lab exercises. Each case ships evidence in the real formats (disk images, registry hives, Windows event logs, Windows crash dumps and Linux LiME memory images, packet captures, mobile extractions, cloud audit logs, EDR and SIEM exports) with a worksheet, an answer key and a grading rubric.

The distinguishing feature is that every student receives a different variant of the same case: names, timestamps, hashes and addresses change per student from one seed, and so do most answers. A copied answer sheet scores about a quarter of the points. The anti-collusion report shows which questions hand several students the same answer and whose keys overlap most. Every fact answer is checked in the evidence before release.

What the trial lets you check

  • Install without an account, generate a three-student First Look lab, and open the evidence in Autopsy, Registry Explorer, EvtxECmd, Wireshark or Volatility.
  • Confirm two students' packages differ, and that the answer key for each matches its own evidence.
  • Grade a submission and read the per-answer explanation; export the scores as a CSV your LMS imports.
  • Open the 14-week forensics and 8-week incident response syllabi and map them to your catalog.
  • Filter the library by GIAC, CompTIA or SANS prep track and by MITRE ATT&CK tactic.
  • Run the student portal on the instructor's machine and submit answers as a student would.

First Look cases run free with no key, for up to five students per lab. The 30-day trial key adds a medium and a hard case in each discipline, also for five students, with watermarked documents. CTF mode and the Scenario Editor need a license.

How a purchase works

  • Card checkout on the website, or a purchase order sent to sales@redherrings.app. A W-9 and a vendor form are available on request.
  • Licenses are annual and renew unless canceled. A license key arrives by email and is activated inside the app; air-gapped machines can activate by file.
  • Department licenses cover three instructors; ask us about larger programs.
  • Full refund within 14 days of purchase; see redherrings.app/refund.html.
