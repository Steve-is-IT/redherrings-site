How Red Herrings works

One case becomes a different, individually verified lab for every student. You generate, hand out, grade and export to your LMS, all on your own machine.

One case, a lab for everyone

Write or pick a case once. Red Herrings seeds it differently for each student, so every learner gets their own hostnames, users, timestamps, file names, hashes and answers, drawn from the same scenario. Nobody can copy a neighbor's answer, and you still only prepared one case.

From zero to a graded class in four steps

  1. Pick a case. Choose from the built-in library across disk, registry, Windows event logs, memory, network (PCAP), mobile and cloud evidence, grouped into certification-prep tracks. Or write your own in the visual editor, or install a pack.
  2. Set the class. Enter a head count or drop in a roster CSV, choose a difficulty (higher difficulty adds decoys and sharper distractors), and set a seed. The same seed and roster reproduce the exact same labs, so you can rebuild a lost package or regenerate on another machine.
  3. Generate. Each student gets a uniquely seeded evidence set in real formats, plus a worksheet, an answer key and a rubric. Every lab is verified as it is built (see below).
  4. Hand out and grade. Give each student only their own zip. Keep the instructor package with the keys. Batch-grade the whole class from the grading sheet, then export grades to your LMS.

Why the answer keys are trustworthy

After each lab is built, Red Herrings re-opens every artifact with an independent parser and confirms that the answer key is actually present in the evidence. That is the green Fresh Catch check on the results screen. If a fact cannot be found in the evidence, the lab is flagged before you ever hand it out, so you are never grading against an answer that is not really there.

Every student gets a different case

Because each variant is seeded independently, the answers differ from student to student. The built-in anti-collusion report shows, per question, how many distinct answers were handed out and which student pairs look most alike, so shared work stands out.

It runs on your machine

Red Herrings is local software for Windows and Linux. Double-click to launch and it opens in your browser. Generation and grading make no network call, and it runs air-gapped if it has to. The only time it contacts a server is to activate, refresh or deactivate a license, and air-gapped machines can do even that by file exchange. No student data ever leaves your computer.

Grading and your LMS

Import the grading sheet to auto-grade the whole class at once, with sensible tolerances and a reason shown for every score. Review class analytics and the per-question correct rate, then export grades in Canvas, Blackboard, Moodle or D2L Brightspace format, or download a case as a Common Cartridge (.imscc) module to import the assignment straight into your LMS.

Guided learning, when you want it

For a stuck learner or self-study, guided mode steps through a question one hint at a time: from a nudge about where to look, to how to work it with the right tool, to the answer. You can also print a guided worksheet with a hint under each question and a tool quick-start appendix. You decide whether learners may reveal full solutions.
